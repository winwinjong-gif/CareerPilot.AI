# CareerPilot.AI

> 대학생의 진로·취업 준비와 기업의 인재 탐색을 연결하는 **다중 AI 에이전트 기반 커리어 플랫폼 기획안**

## 프로젝트 성격

CareerPilot.AI는 개인 학술 기획 및 IR 발표 프로젝트입니다.  
실제 웹 서비스, AI 모델, API, 데이터 파이프라인을 구현한 결과물이 아니라, 취업 문제를 해결하기 위한 서비스 구조·다중 에이전트 설계·사업 모델을 제안한 포트폴리오입니다.

| 구분 | 내용 |
| --- | --- |
| 프로젝트 유형 | AI 기반 커리어 플랫폼 서비스 기획 및 IR 발표 |
| 수행 형태 | 개인 프로젝트 |
| 주요 대상 | 대학생·취업 준비생, 대학 취업지원센터, 기업 인사 담당자 |
| 핵심 개념 | 다중 AI 에이전트, 개인화 추천, 인재 매칭 |
| 구현 상태 | 기획 완료 · 미구현 |

## 문제 정의

취업 준비생은 자신의 역량·가치관·희망 직무에 맞는 기업과 준비 방향을 찾기 위해 많은 정보를 개별적으로 탐색해야 합니다. 반대로 기업은 채용 기준과 조직 문화에 맞는 인재를 선별하는 데 시간과 비용을 사용합니다.

CareerPilot.AI는 학생에게는 개인화된 진로·취업 전략을, 기업에는 적합한 인재 탐색을 지원하는 양면 플랫폼을 제안합니다.

## 서비스 구조

| 영역 | 대상 | 제안 가치 |
| --- | --- | --- |
| B2C | 대학생·취업 준비생 | 목표 설정, 기업 추천, 취업 전략, 서류·포트폴리오 개선 방향 지원 |
| B2B | 기업·인사 담당자 | 인재상 분석, 후보자 매칭, 인재 소싱, 스카우트 커뮤니케이션 지원 |
| B2U | 대학 취업지원센터 | 학생의 진로·취업 준비를 지원하는 서비스 제공 채널 |

## 다중 AI 에이전트 설계

역할별 에이전트가 협력하는 구조를 제안했습니다.

### 학생·취업 준비생 지원

| 에이전트 | 제안 역할 |
| --- | --- |
| 목표 설계 에이전트 | 희망 직무·연봉·근무 환경·가치관을 바탕으로 진로 목표 설정 |
| 정보 수집 에이전트 | 채용 공고와 기업 정보를 수집·정리 |
| 추천 에이전트 | 사용자 조건과 선호도를 반영해 적합한 기업 및 준비 전략 제안 |
| 서류·포트폴리오 에이전트 | 지원 기업에 맞는 자기소개서와 포트폴리오 개선 방향 제안 |
| 피드백 에이전트 | 결과를 검토하고 보완이 필요한 부분에 대한 피드백 제공 |

### 기업 지원

| 에이전트 | 제안 역할 |
| --- | --- |
| 인재상 분석 에이전트 | 기업의 조직 문화·직무·채용 기준을 바탕으로 인재상 분석 |
| 인재 매칭 에이전트 | 기업 조건과 지원자 프로필 간 적합도 분석 |
| 인재 발굴 에이전트 | 조건에 부합하는 후보자 탐색 및 선별 지원 |
| 소통 지원 에이전트 | 스카우트 메시지 작성 및 전달 과정 지원 |
| 최적화 에이전트 | 채용 결과를 바탕으로 추천 기준을 개선하는 구조 제안 |

```text
목표·조건 입력
  → 채용 공고·기업 정보 탐색
  → 역할별 에이전트의 분석 및 추론
  → 기업·전략 추천
  → 서류·포트폴리오·취업 준비 피드백
```

## 제안 기술 구성

아래 항목은 실제 구현 기술이 아니라, 서비스 구현을 가정해 검토한 아키텍처입니다.

- 대규모 언어 모델(LLM) 기반 추론
- RAG 기반 채용 공고·기업 정보 탐색
- 벡터 데이터베이스 기반 정보 검색
- 목표 기반·모델 기반·효용 기반 에이전트의 역할 분담
- 결과 검토와 개선을 위한 피드백 구조

## 개인 수행 범위

- 취업 준비와 기업 인재 탐색 과정의 문제 정의
- CareerPilot.AI 서비스 콘셉트 및 사용자 가치 제안 설계
- 학생 대상 B2C 서비스와 기업 대상 B2B 서비스 구조 기획
- 다중 AI 에이전트의 역할 분담 및 서비스 흐름 설계
- 시장 진입 전략, 운영 계획, 수익화 방향을 포함한 IR 자료 작성
- 기획 보고서 및 발표 자료 제작

## 한계 및 유의 사항

- 실제 학습 모델, 웹 서비스, 외부 API 연동, 데이터 수집·처리 파이프라인은 포함하지 않습니다.
- 추천 정확도·인재 매칭 성능·사용자 만족도는 실제 데이터와 실험으로 검증하지 않았습니다.
- 문서의 시장 규모, 사용자 수, 투자금, 비용, 매출 전망은 기획을 위한 가정과 추정치이며, 실제 실적 또는 투자 권유가 아닙니다.
- 실제 서비스로 발전시키려면 개인정보 보호, 사용자 동의, 데이터 소유권, 추천 편향, 설명 가능성, 보안 및 채용 관련 법적 검토가 필요합니다.
